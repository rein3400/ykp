DEVELOPER BRIEF — YKP ERP FINANCE MODULE V1

1. PROJECT CONTEXT

YKP sedang membangun ERP internal untuk beberapa brand F&B:
- Funkydak
- Sekarpizza
- Suburbuns
- Laju Kopi
- Uncle Masala

Untuk tahap awal, fokus pertama adalah Finance Module, karena dashboard finance sudah ada secara visual, tetapi belum running dengan data YKP.

Targetnya bukan membangun ulang dari nol, tetapi:

Clone / lanjutkan Finance Web App existing
→ ganti database/spreadsheet ke database YKP
→ isi master data YKP
→ migrasi data finance
→ test angka
→ running untuk 1 brand pilot


2. TUJUAN FINANCE MODULE

Finance Module harus menjadi pusat kontrol uang YKP.

Fokus utama:
1. Mencatat pendapatan POS.
2. Mencatat pembelian supplier.
3. Mencatat petty cash.
4. Mencatat expense.
5. Melihat unpaid bills.
6. Melihat saldo dan cashflow.
7. Melihat profit kasar per brand/outlet.
8. Menyiapkan summary finance agar nanti bisa dibaca oleh Orchestration Layer dan Hermez AI.


3. STATUS SAAT INI

Finance App:
- Visual/dashboard sudah ada.
- Belum running dengan data asli YKP.
- Database masih perlu diganti ke spreadsheet/database YKP.
- Data dummy harus dibersihkan.
- Perlu mapping ulang brand, outlet, supplier, POS, expense, dan petty cash.

Database Awal:
Untuk V1, database boleh menggunakan:
Google Sheet / Spreadsheet Database

Nanti jika sudah stabil, bisa migrasi ke:
PostgreSQL / Supabase / Firebase

11. ALERT RULES FINANCE V1

Rules awal:
- cash_difference > Rp50.000 = HIGH
- unpaid_supplier overdue = MEDIUM/HIGH
- petty_cash_out > limit harian = MEDIUM
- expense naik > 20% dari rata-rata 7 hari = MEDIUM
- supplier_cost naik > 15% = MEDIUM/HIGH
- missing receipt = LOW/MEDIUM
- net profit minus = HIGH
- refund/void tinggi = MEDIUM/HIGH

18. ONE-LINER DEVELOPER

Finance Module V1 adalah proses mengaktifkan Finance Web App existing agar berjalan dengan data YKP, memakai spreadsheet/database YKP baru, mencatat POS revenue, supplier costing, petty cash, expense, unpaid bills, dan menghasilkan finance daily summary yang siap dibaca Orchestration Layer dan Hermez AI.


PESAN SINGKAT KE DEVELOPER

Mas, kita mulai dari Finance ERP dulu. App finance yang sudah ada jangan dibangun ulang dari nol, tapi diclone, diganti database/spreadsheet-nya ke data YKP, dummy data dibersihkan, lalu dimapping ke master brand/outlet/supplier/kategori biaya. Fokus V1: POS revenue, supplier costing, petty cash, expense, unpaid supplier, finance summary, filter brand/outlet/periode, export basic, dan pilot 1 brand dulu. Belum masuk Moka API real-time, Hermez full, Operational, Marketing, atau database migration.
