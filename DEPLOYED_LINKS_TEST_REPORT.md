## Issues found

1. **Operational Vercel login loop** — `https://ykp-ops-v1.vercel.app/login` accepts credentials but does not establish session. Button text changes to `Masuk…` then returns to login. This matches the app being in mock mode but possibly missing `SESSION_SECRET` or `USE_MOCK_DB=true` env on production, or the seed user not matching `owner/owner123`.

2. **Warehouse client-side routing / 404 on direct URLs** — Sub-pages (e.g. `/master-item`, `/alerts`) return 404 when accessed directly. The app only works if you navigate from the overview via client-side links. Suggests the Vercel `rewrites` config is missing `/:path*` fallback or the routes are not actually implemented as pages.

3. **HR Pilot Vercel login form issue** — Password input has no `name` attribute, form uses `method="get"`, and validation fails. This is a frontend form bug, not a deployment connectivity issue. The Railway version of the same app logs in successfully.
