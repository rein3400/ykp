Part 1 - Roadmap YKP ERP + Hermez
1. Project Overview
YKP wants to build an internal ERP for multi-brand F&B operations covering Funkydak, Sekarpizza, Suburbuns, Laju Kopi, 
and Uncle Masala. The strategy is modular: use existing apps where possible, stabilize data first, then add orchestration and 
AI.

4. Non-Negotiable Principles
 Do not build all modules at once.
 Start with HR and Finance because both apps already exist.
 V1 can use spreadsheet/Google Sheet, but structure must be clean and migration-ready.
 All modules must share the same master data: brand, outlet, employee, supplier, menu, expense category.
 Every module must produce daily summary sheets.
 Hermez is not the input app. Hermez reads summary and gives insight.
 Every important process must have timestamp, PIC/user, and audit log.

6. Developer Technical Tasks
6.1 Audit Existing Apps
 Check old Spreadsheet ID and sheet tabs.
 Check column structure and data types.
 Find hardcoded formulas or dummy brand/outlet names.
 Check role/user access and auth flow.
 List known bugs and reusable components.
6.2 Clone Apps
 Create YKP HR App Testing and YKP Finance App Testing.
 After validation, create YKP HR App Production and YKP Finance App Production.
 Do not edit old app without backup.
6.3 Replace Database Source
 Replace old spreadsheet/database source with YKP database.
 Ensure every page reads from new source.
 Ensure every form writes to new source.
 Ensure filters use YKP master data.
 Remove all dummy data from production.
6.4 HR Migration
 Import employees and shift rules.
 Setup late tolerance and deduction rules.
 Setup payroll, bonus, and penalty logic.
 Test attendance check-in/check-out.
 Generate hr_daily_summary.
6.5 Finance Migration
 Import suppliers and expense categories.
 Setup POS revenue import/export from Moka.
 Setup supplier costing, petty cash, expenses, unpaid supplier.
 Validate revenue against Moka export.
 Generate fin_daily_summary.
7. Pilot Test
Pilot should be done with 1 brand or 1 outlet for 7-14 days. Recommended options: Funkydak if YKP wants to test the most 
complex data, or Suburbuns if YKP wants a more stable and cleaner first pilot.
 HR attendance
 Payroll simulation
 Finance input
 Supplier costing
 Petty cash
 POS revenue
 Daily summaries

9. Risks & Mitigation
Risk Mitigation
YKP data is not clean Start with simple master data; do not wait for perfection.
Hardcoded formulas in old apps Audit all formulas and sheet references before migration.
Dummy data mixed with production Create new production spreadsheets and remove dummy data before 
go-live.
Payroll mismatch Manual test 5-10 employees before full use.
Finance mismatch with Moka Reconcile daily revenue with Moka export.
Scope creep Phase 1 is HR + Finance only. Operational, Marketing, Orchestration, 
Hermez are later.
